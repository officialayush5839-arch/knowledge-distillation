# Knowledge Distillation (KD-Edge-TinyML)

Reproducible research and benchmarking framework investigating the transfer of foundation model knowledge into compact, quantized edge models under resource constraints and domain shift.

---

## 📌 Project Overview

This repository establishes a rigorous, specification-driven framework for edge and TinyML knowledge distillation. It bridges high-capacity teacher representations and resource-constrained student architectures with verified software resource budgets (latency, memory footprint, throughput, and Pareto frontier analysis).
